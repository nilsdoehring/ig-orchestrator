# kh publish

Publish a brand's reviewed atoms to the live tables, pruning what was retired. The run declares the dimensions it speaks for.

This mirrors the Hub's `POST /webhook/kh/publish` endpoint, so the repository and the
API stay recognisably the same product. When the Hub is reachable, prefer the endpoint —
it reads the live corpus. This bundle is the offline copy.
