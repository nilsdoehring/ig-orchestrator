# kh ingest

Digest a document into draft atoms through its dimension's expert skill. Atoms land as drafts; nothing publishes itself.

This mirrors the Hub's `POST /webhook/kh/ingest` endpoint, so the repository and the
API stay recognisably the same product. When the Hub is reachable, prefer the endpoint —
it reads the live corpus. This bundle is the offline copy.
