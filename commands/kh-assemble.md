# kh assemble

Assemble a system prompt for a skill, inside one brand, at one scope. Returns the prompt and the atoms that produced it.

This mirrors the Hub's `POST /webhook/kh/assemble` endpoint, so the repository and the
API stay recognisably the same product. When the Hub is reachable, prefer the endpoint —
it reads the live corpus. This bundle is the offline copy.
