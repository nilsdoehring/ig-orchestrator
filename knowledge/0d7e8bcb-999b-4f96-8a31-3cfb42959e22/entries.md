tag and as a `scope` value when assembling.

the prompt comes back built from fewer atoms than you expected, with no warning — which is
why this file exists rather than leaving you to infer values from the shelves.

`*` appears in no table here. It is an atom's way of saying "every value on this
axis", not a value this brand owns, and it is never a legal scope value.
